        Rigless sends its work to , set by COMFY_BASE_URL in .env. Remove it there to choose here.

        Starts a pod with a 100 GB disk wherever RunPod has this GPU free. It downloads the models first, roughly 25 minutes. Afterwards you can pause it (the disk costs $20/month while paused) or delete it.

        Rigless sends its work to ComfyUI on this computer through comfy-api-proxy at http://127.0.0.1:8189. It needs a GPU with 48 GB or more, and both running first; the README shows how.
